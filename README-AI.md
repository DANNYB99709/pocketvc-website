# AI/LLM Optimization Files

This directory contains files specifically designed to help AI systems (like ChatGPT, Claude, Perplexity) discover and understand PocketVC.

## Files Overview

### `ai-content.txt`
- **Purpose**: Comprehensive company overview for AI training
- **Content**: Company details, services, target audience, technical stack
- **Usage**: Helps AI understand business context and provide accurate information

### `ai-structured-data.json`
- **Purpose**: Structured organization data in JSON-LD format
- **Content**: Schema.org compliant company information
- **Usage**: Provides structured context for AI systems and search engines

### `ai-training-data.json`
- **Purpose**: Comprehensive training data for AI systems
- **Content**: Detailed company profile, services, keywords, contact info
- **Usage**: Primary source for AI systems to understand PocketVC

### `ai-company-profile.md`
- **Purpose**: Human-readable company profile optimized for AI
- **Content**: Detailed company information, mission, services, timeline
- **Usage**: Reference document for AI systems and human readers

## How These Help LLM Discovery

1. **Structured Data**: JSON files provide clear, parseable information
2. **Comprehensive Coverage**: Multiple formats ensure different AI systems can access information
3. **Keyword Optimization**: Files include relevant keywords for discovery
4. **Contact Information**: Clear paths for users to find and contact PocketVC
5. **Regular Updates**: Files should be updated as company evolves

## Maintenance

- Update these files when company information changes
- Add new keywords as business evolves
- Ensure contact information remains current
- Review and update quarterly
